# 00 — LEIA PRIMEIRO

Este arquivo orienta qualquer pessoa ou IA que for trabalhar no ecossistema Relacione-se para manter consistencia, clareza e organizacao.

## Ordem obrigatoria de leitura

1. `01-BIBLIA-MESTRE-RELACIONE-SE.md`
2. `03-GLOSSARIO-OFICIAL.md`
3. `04-ARQUITETURA-SITE.md`
4. O arquivo especifico do tema em trabalho.

## Regra principal

O site mostra a arvore. Este repositorio guarda as raizes.

Nem toda informacao forte deve ir para o site. Primeiro ela deve ser registrada, classificada e lapidada.

## Nomes oficiais preservados

- Relacione-se
- Metodo Posicione-se
- Reposicione-se
- Arvore do Discernimento
- MINDSETmagro
- Magnetus

- Matematica do Perdao
- Modos operantes
- Sua arvore, seus frutos
- Fruto nao mente
- Acesse seus recursos internos

## O que nao fazer

- Nao inventar fatos.
- Nao trocar nomes oficiais sem registrar decisao aprovada.
- Nao misturar produtos diferentes como se fossem a mesma coisa.
- Nao transformar Magnetus em manual barato de seducao.
- Nao transformar MINDSETmagro em dieta milagrosa.
- Nao expor personagens familiares de forma crua no site.
- Nao tratar a historia como fofoca ou espetaculo.
- Nao prometer resultados medicos, corporais ou emocionais garantidos.
- Nao resumir Sol Lima como uma marca generica de autoestima.

## Como classificar informacoes novas

Use estas etiquetas:

- `[BRUTO]` informacao recebida, ainda nao lapidada.
- `[APROVADO]` pode virar texto oficial.
- `[PRIVADO]` deve ficar apenas como contexto interno.
- `[PUBLICO]` pode ser usado no site.
- `[PRODUTO]` pertence a produto especifico.
- `[BLOG]` melhor virar artigo.
- `[LIVRO]` guardar para narrativa longa.
