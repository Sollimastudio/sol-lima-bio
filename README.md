# Relacione-se — Repositório Mestre

Este repositório organiza a Bíblia da Marca Relacione-se, a história autoral da Sol Lima, o Método Posicione-se™, os produtos derivados e a arquitetura do site `relacione-se.com`.

## Como usar

Comece sempre por:

1. `00-LEIA-PRIMEIRO.md`
2. `01-BIBLIA-MESTRE-RELACIONE-SE.md`
3. `03-GLOSSARIO-OFICIAL.md`
4. O arquivo específico do produto, página ou tema em trabalho.

## Estrutura inicial

- `00-LEIA-PRIMEIRO.md` — regras para qualquer IA ou pessoa que for trabalhar no projeto.
- `01-BIBLIA-MESTRE-RELACIONE-SE.md` — síntese da marca, origem, missão e arquitetura emocional.
- `02-LINHA-DO-TEMPO.md` — ordem dos acontecimentos e nascimento dos produtos.
- `03-GLOSSARIO-OFICIAL.md` — vocabulário oficial do ecossistema.
- `04-ARQUITETURA-SITE.md` — mapa do site e função de cada página.
- `metodo-posicione-se/arvore-do-discernimento.md` — ferramenta central do método.
- `produtos/magnetus/origem-do-magnetus.md` — origem e função do Magnetus.
- `produtos/mindsetmagro/origem-do-mindsetmagro.md` — Mãe Véia, desobesidade emocional e corpo como fruto.

## Regra-mãe

O site mostra a árvore. Este repositório guarda as raízes.

Nada deve ser publicado de forma crua apenas por ser forte. Toda informação precisa passar por função narrativa, cuidado ético e uso estratégico.
