# Manifesto de Exportacao do Publisher

O pacote final premium deve conter:

## HTML / WebBook

Arquivo interativo, responsivo e navegavel.

## PDF Premium

Arquivo paginado, diagramado, pronto para leitura e venda.

## DOCX Editavel

Arquivo editavel, com estrutura visual e blocos organizados.

## Pacote Visual

Imagens, diagramas, ideogramas, placeholders, prompts visuais e elementos graficos.

## ZIP Final

Pasta compactada contendo todas as versoes e documentos de apoio.

## Regra

Nenhum item entra no pacote final sem passar pelo Cofre Editorial ou pelo Artefato Editorial com status aprovado ou final.

## Proxima implementacao

Criar exportador PDF a partir do HTML.
Criar exportador DOCX a partir do Artefato Editorial.
Criar gerador ZIP com todas as saidas.
