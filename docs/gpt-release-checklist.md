# Checklist para liberar o GPT Publisher IA

## Objetivo

Liberar o GPT dentro do ChatGPT como vitrine inteligente do Publisher.

## Configuracao no Builder

1. Nome
Publisher IA - Criador de eBooks Premium

2. Descricao curta
Transforma ideias, manuscritos, posts e aulas em eBooks, livros, workbooks e WebBooks profissionais, sem exigir prompts tecnicos.

3. Instrucoes
Usar o arquivo:
gpt-store/publisher-gpt-instrucoes-publicas.md

4. Mensagem inicial
Usar o arquivo:
gpt-store/publisher-gpt-mensagem-inicial.md

5. Quebra gelos
Usar o arquivo:
gpt-store/publisher-gpt-quebra-gelos.md

6. Oferta Premium
Usar o arquivo:
gpt-store/publisher-gpt-oferta-premium.md

## Conhecimentos recomendados

Anexar documentos com:

- esteira editorial do Publisher
- regras de modo guiado sem prompts
- temas editoriais
- cofre editorial
- artefato editorial
- limites entre gratuito e premium

## Fluxo gratuito

O GPT pode entregar:

- entrevista guiada
- memoria inicial
- diagnostico editorial
- recomendacao de estrutura
- plano inicial

## Fluxo Premium

Quando o usuario pedir arquivos finais completos, oferecer Premium para:

- escrita por blocos
- revisao
- design
- diagramas
- HTML
- PDF
- DOCX
- pacote final

## Antes de publicar

- Testar com 3 pedidos simples
- Testar com 1 manuscrito
- Testar se ele oferece Premium sem ficar repetitivo
- Testar se ele nao pede prompts tecnicos
- Testar se ele conduz para proxima etapa
